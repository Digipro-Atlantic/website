# Zebul website (zebul.ng)

Static multi-page site. Every page is self-contained (styles and scripts are inline),
so it deploys to any static host or can be opened directly from disk.

## Pages
- index.html        Home
- platform.html     Platform capabilities, marketplace and API
- financing.html    Tenant rent financing
- estates.html      Community-Governed Estate Module
- institutions.html Bulk and institutional housing
- pricing.html      Pricing and fees
- security.html     Trust and compliance
- faq.html          Frequently asked questions
- demo.html         Book a demo (request form)
- signin.html       Sign in and create account
- partners.html     Become a partner
- tour.html         See the platform (visual product tour)

## Deploy
Upload the folder to any static host (Netlify, Vercel, Cloudflare Pages, S3, Nginx).
No build step. Set index.html as the entry document.
